RoboTwin-Clean 物体局部小图

15类，每类3张，共45张PNG。按用户提供的瓶子小图示例，
从真实RoboTwin-Clean轨迹画面中紧凑裁剪到目标物体附近，只保留少量周围背景。

单张PNG保持裁剪区域的原始像素，不拉伸、不放大、不调色、不生成补全。
尺寸随物体形状不同而不同。总览图及网页中的缩放仅用于浏览。
解压后打开index.html，可以查看全部小图。
每张图的任务、episode、视频时间、来源视频和裁剪框详见sources.csv。
裁剪坐标基于原始640×480图像，采用左、上包含，右、下不包含的像素坐标。

物体外观如实保留数据集内容，包括包装、阴影及原场景中靠近物体的局部背景。
